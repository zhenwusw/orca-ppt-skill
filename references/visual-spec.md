# 视觉规范（汇报稿）

转场能对上的前提，是前后两页的元素落在同一套网格、字号、颜色上。
所以这份规范约束得比一般幻灯片模板更死：**只许用这里列出来的值。**
故事稿（整页照片）的规范见 `story-mode.md`。

## 画布和网格

- 画布 1920×1080。每页的直接子元素都绝对定位：`style="left:…px; top:…px;"`。
- **面板、卡片这类形状，坐标和尺寸取 40 的倍数。**
- 可以不是 40 倍数的情况：
  - 文字的 `top`，用来在卡片里垂直对齐。
  - 居中文字的 `left`，按公式算出来是多少就写多少。
  - 图表里柱子、条的长度，按数据比例算，取整到 1px。
- 安全区：左右 120，上下 80。内容不许超出 `left 120 ~ 1800`、`top 80 ~ 1000`。
- 内容区宽 1680。常用分栏：
  - 两栏：`left:120 width:800` + `left:1000 width:800`（栏距 80）
  - 三栏：`left:120 / 680 / 1240`，每栏 `width:520`（栏距 40）

## 文字

只能用这五个字号类，不许在 style 里写 `font-size`、`color`：

| 类 | 字号 | 用在哪 | 一行最多 |
| --- | --- | --- | --- |
| `.t-display` | 160 | 封面标题，章节标题，结尾；数字卡片里的数字。见下 | 8 个字 |
| `.t-metric` | 280 | 关键数字，自带强调色。一页最多一个 | 见下 |
| `.t-h1` | 72 | 内容页标题 | 20 个字 |
| `.t-h2` | 48 | 条目，卡片标题 | 按 width 换行 |
| `.t-body` | 36 | 说明文字，暗色 | 按 width 换行 |

修饰类：`.t-accent`（强调色），`.t-dim`（暗色）。

**`.t-display` 的数量**：
- 当标题用（封面、章节、结尾）时，一页只有一个。
- 当数字卡片里的数字用时（几张卡片各放一个大数字），每张卡片一个，一页最多 3 个。
  这样的页面不再用 `.t-display` 做标题，也不和 `.t-metric` 放进同一张卡片。

**估算宽度**：
- 中文字：宽 ≈ 字号。
- 数字、英文、小数点：宽 ≈ 0.55 × 字号。`.t-metric` 的「18.6」≈ 4 × 154 = 616px。
- 「万」「%」这类放在数字后面的，按中文字算。

**需要换行的 `.t-h2` `.t-body` 必须写 `width`。**

**居中**：可以在 style 里写 `text-align:center`，同时写 `width`，`left` 按「中心 − width/2」算。

**文字标签**：一律用 `<p>`。只有做共享元素时，前后两页的标签必须一致，统一用 `<p>` 最省事。

## 颜色和形状

不许在 style 里写颜色，只用这些类。下表写的是默认主题的样子，换主题后颜色跟着变，用途不变（见 `themes.md`）：

| 类 | 样子 | 用在哪 |
| --- | --- | --- |
| `.s-surface` | 深灰面板，大圆角 | 内容卡片，大面板 |
| `.s-surface-2` | 浅一级的灰，中圆角 | 面板里面的小卡片，图表的普通柱 |
| `.s-accent` | 橙色，小圆角 | 强调条，图表的重点柱，分割线 |
| `.s-accent-soft` | 暗橙，中圆角 | 高亮卡片，高亮行的底 |
| `.s-dot` | 橙色正圆 | 圆点，图标底，徽章 |

线条类（只用在 `<svg>` 里的 `path` / `polyline` / `line` 上）：`.l-accent` `.l-surface` `.l-text` 线宽 6，`.l-dim` 线宽 2（基线、参考线）。
不许在 svg 上写 `stroke` 颜色，虚线可以写 `stroke-dasharray`。

文字颜色类 `.t-on-surface`：放在 `.s-surface` 形状上面的文字用它。默认主题下和普通文字同色，浅色主题下会变成浅色。

- 形状元素写 `left top width height`。`.s-dot` 的宽高必须相等。
- 要一个暗橙色的圆，写 `class="s-accent-soft" style="…; border-radius:50%;"`。圆角只许写 `50%`；铺满画布的整页形状写 `0`（见 `transitions.md`「整页 ↔ 卡片」）。
- **强调色（`.s-accent` `.s-dot` `.t-metric` `.t-accent`）的面积加起来，不超过画面的 15%。**
  满屏橙色只出现在遮挡剪辑的色块里。

## 页面类型

每页只放一个主角。照这些坐标摆，前后页才对得上。

### 封面
- 标题 `.t-display`：水平居中，`top:400`
- 副标题 `.t-body`：`top:600`，`width:1200 text-align:center left:360`
- 装饰（`.s-accent` 横条或 `.s-dot`）：`top:680` 附近，水平居中

### 章节页
- `.t-body`「第 N 部分」：`left:120 top:360`
- `.t-display` 章节名：`left:120 top:440`

### 列表页（标题 + 面板 + 条目）
- 标题 `.t-h1`：`left:120 top:80`
- 面板 `.s-surface`：`left:120 top:240 width:1680 height:760`
- 条目：`left:200` 起。
  - 单行条目（只有 `.t-h2`）：第一行 `top:320`，行距 120，最多 6 行。
  - 双行条目（`.t-h2` + 下面一行 `.t-body`）：`.t-body` 在 `.t-h2` 下方 72，行距 200，最多 3 条。
- 条目右侧的数值 `.t-body`：`left:1360`，`top` 比同行 `.t-h2` 多 6。
- 高亮某一行：`.s-accent-soft`，`left:160 width:1600 height:120`，`top` 比 `.t-h2` 少 40。

### 数据页
- 标题 `.t-h1`：`left:120 top:80`
- 数字 `.t-metric`：`left:120 top:320`（宽度不超过 800）
- 数字说明 `.t-h2`：`left:120 top:680`；补充 `.t-body`：`left:120 top:760 width:800`
- 右侧面板 `.s-surface`：`left:1000 top:240 width:800 height:760`，里面可以放：
  - **柱状图**：面板里柱子可用宽度 640（`left:1080` 到 `1720`）。按根数取柱宽和间距：

    | 根数 | 柱宽 | 间距 | 各柱 `left` |
    | --- | --- | --- | --- |
    | 3 | 120 | 140 | 1080 / 1340 / 1600 |
    | 4 | 100 | 80 | 1080 / 1260 / 1440 / 1620 |
    | 5 | 80 | 60 | 1080 / 1220 / 1360 / 1500 / 1640 |

    底边对齐 `top+height = 880`，最高的柱高 440，其他按数据比例算。
    柱下标签 `.t-body`：`top:900`，`width` 等于柱宽加间距，居中在柱子下面。
    普通柱 `.s-surface-2`，重点柱 `.s-accent`。柱子写 `data-enter="grow-up"`，
    底部加一条坐标轴 `.s-accent`：`left:1040 width:720 height:4`，`top` 等于柱子底边。
  - **折线图**：一个 `<svg>`，`left:1040 top:320 width:720 height:480`，`viewBox="0 0 720 480"`（单位就是像素）。
    - 每条线一个 `<path>`，类用 `.l-accent`（重点线）`.l-surface` `.l-text`，最多 3 条。坐标在 viewBox 里按数据比例算。
    - 基线和参考线另放一个 `<svg>`（同位置同尺寸），用 `.l-dim`，不写 `data-enter="draw"`，先于折线出现。
    - 折线的 `<svg>` 写 `data-enter="draw"`，线的顺序就是画的顺序，重点线放最后。
    - 线尾的数值 `.t-body` 或主题的小标签放在线的终点右边 16px，在所有线画完后出（延迟 ≈ 折线延迟 + 0.15 × 条数 + 0.6）。
  - **排行**：`.t-h2` 名称 `left:1080`，数值 `.t-h2 .t-accent` `left:1600`，行距 120，第一行 `top:320`。
  - **一个徽章**：`.s-dot` 或暗橙圆，`width/height:320`，中心 `(1400, 560)`；名称 `.t-h2` 居中在 `top:760`。

### 对比页
- 标题 `.t-h1`：`left:120 top:80`
- 两个面板：`left:120` 和 `left:1000`，`top:240 width:800 height:760`
- 强调的一侧 `.s-accent-soft`，另一侧 `.s-surface`

### 结尾页
- `.t-display`：水平居中，`top:400`
- 一行 `.t-body`：`top:600`，`width:1200 text-align:center left:360`

## 为转场预留

- 做共享元素的元素，前后两页都用上面的标准位置，不要自己发明中间位置。
- 做元素交接的两页，用同一种页面类型（数据页 → 数据页）。
- 做匹配放大的两个元素，先定中心点，再算 `left = cx − width/2`。
